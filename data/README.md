# Project data

## data/raw (original files, never modified)
- Delitos_Informaticos_V1_20261010.xlsx: cybercrime cases (Colombian Law 1273 of 2009), datos.gov.co.
  Date taken from the file name: Oct 10, 2026. Downloaded on Nov 10, 2026.
  [Confirm the publishing entity on the dataset page.]
- PhiUSIIL_Phishing_URL_Dataset.csv: NOT in the repository (54 MB).
  Download from https://archive.ics.uci.edu/dataset/967/phiusiil+phishing+url+website+dataset
  and save it in data/raw/. Prasad & Chandra. Published in 2024. License CC BY 4.0.
- PPED-AreaMun-2018-2042_VP.xlsx: NOT in the repository.
  Municipal population by area, 2018-2042 (DANE, projections based on the 2018 Census,
  published on Aug 8, 2025). Download "Serie municipal de población por área, para el periodo
  2018-2042" from https://www.dane.gov.co/index.php/estadisticas-por-tema/demografia-y-poblacion/proyecciones-de-poblacion
  and save it in data/raw/.

## data/processed
- crimes_processed.csv: generated by analysis/03_cleaning.py
- summary_year_category.csv and summary_department_category.csv: analysis/06_eda_crimes.py
- rates_department_year.csv and rates_municipality_year.csv: cases per 100,000 inhabitants
  (2018-2025), generated by analysis/08_population_merge.py
- phishing_processed.csv: NOT in the repository. Generated by analysis/05_prepare_phishing.py.
  The `split` column (train/val/test) is grouped by domain.
- feature_groups.json: url_only, derived and page features.

## Charts
- analysis/figures/: exploratory analysis charts (01 to 10).

## How to reproduce
Run from the repository root:
```
pip install -r requirements-analysis.txt
python analysis/03_cleaning.py
python analysis/05_prepare_phishing.py
python analysis/06_eda_crimes.py
python analysis/08_population_merge.py
python analysis/09_rate_charts.py
```
