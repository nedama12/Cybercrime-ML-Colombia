Selected sources and features

The classification model is trained only with PhiUSIIL, because it is the only source with labeled URLs. The Colombian cybercrime data and the DANE population projections are processed for context indicators and reports. The 50 PhiUSIIL predictors were organized in three groups (data/processed/feature_groups.json):

GroupCountExamplesAvailable at prediction time?
url_only18URLLength, NoOfSubDomain, IsHTTPS, LetterRatioInURL, NoOfOtherSpecialCharsInURLYes, computed from the URL text
derived4URLSimilarityIndex, TLDLegitimateProb, URLCharProb, CharContinuationRatePartially; some depend on statistics of the original dataset
page28HasPasswordField, NoOfExternalRef, HasTitle, NoOfJSNo, they require downloading and parsing the web page

Selecting features that the deployed system can compute from the URL alone keeps training and production consistent and avoids visiting potentially malicious pages from the server.

Cleaning: missing values, duplicates, inconsistencies and outliers

PhiUSIIL (analysis/05_prepare_phishing.py)

  1. Label made explicit: is_phishing = 1 when the original label = 0 (in PhiUSIIL, 1 means legitimate).
  2. URLs repeated with contradictory labels were removed; the remaining duplicated URLs were dropped (first occurrence kept).
  3. Columns without predictive use were dropped: FILENAME, Title and the original label.
  4. No missing values were found. Extreme values (for example very long URLs) were kept because they are a real signal of phishing, and tree models are robust to them.

Colombian cybercrime data (analysis/03_cleaning.py)

  1. Years and case totals converted to integers, reporting non-numeric values first.
  2. Whitespace stripped and "SIN DATO" (no data) converted to missing values.
  3. 22 rows without department or municipality removed; empty columns (GRUPO_DELITO, CONSUMADO, PAÍS_HECHO) dropped.
  4. Place names normalized (accents and symbols) to merge with DANE population data.
  5. Article (269A-269J) extracted from the offense text and mapped to a category; aggravating factor flagged.
  6. Spanish YES/NO values encoded as 1/0, partial year 2026 flagged and columns renamed to English.

Transformations and feature engineering

  • Rates per 100,000 inhabitants (analysis/08_population_merge.py): cases are divided by DANE population per department and municipality, so large and small territories can be compared.
  • Scaling: needed only for Logistic Regression. It is fitted inside a scikit-learn Pipeline on the training partition only, so validation and test data never influence it.
  • Encoding: the URL-based predictors are already numeric or binary; no categorical encoding is required for the model.

Partitions without data leakage

The data was split 70% / 15% / 15% into training, validation and test with GroupShuffleSplit grouped by domain (random_state = 42). All URLs of the same domain fall in the same partition, so the model cannot memorize a domain in training and recognize it again in the test set. The overlap of domains between training and test is zero.
