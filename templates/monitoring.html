  • Data drift: weekly PSI of the channel, the affected assets and the predicted categories against models/report_reference_stats.json, saved at training time.

{% endcall %} {% call fold('Risks, quality controls and update procedure', kicker='6.5') %}
  • Quality controls: 21 automated tests (accounts, reports, privacy, review, classifier) and python -m src.verify_models must pass before any deployment.
  • Update procedure: retrain → compare the new version with the current one on the same test and holdout → deploy only if macro F1 does not drop → new version string in the info JSON → keep the previous files to roll back.
  • Risks: new fraud types, change in how people write, mislabelled confirmations, and analysts trusting the model blindly. Controls: drift alerts, a second analyst for corrected categories, and the confidence always visible.
